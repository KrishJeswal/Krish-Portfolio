# krish-jeswal.web.app

Personal portfolio of **Krish Jeswal** — undergrad researcher and full-stack engineer at R.V. College of Engineering, Bengaluru.

→ **[krish-jeswal.web.app](https://krish-jeswal.web.app)**

---

## What's inside

A custom-built portfolio with no UI framework — just React 19, Three.js, and GSAP doing everything from scratch.

- **Hero** — 6500-particle WebGL sphere with a custom simplex-noise GLSL vertex shader, mouse-reactive and scroll-driven
- **Projects** — bento grid showcasing CipherTrace (ML side-channel attack on masked AES-128, submitted to IEEE Access), Code Noir (RAG pipeline on GCP Cloud Run), Intelligent Excel Parser, and the IETE Student Forum
- **Tech Stack** — 3×2 card grid with scramble-text animations across 40+ tools
- **Timeline** — education, experience, and research milestones
- **Contact** — Formspree-backed form

Fully accessible: honors `prefers-reduced-motion` throughout.

## Built with

`React 19` `TypeScript` `Vite` `Three.js` `GSAP` `CSS custom properties`

## Run locally

```bash
npm install
npm run dev
```
